Magic Clipboard

Clicking Pop out moves the real clipboard node into an always-on-top Document Picture-in-Picture window that floats above a separate PACS or viewer. It stays bound to the report form on this page, so dictation in the floating window autofills the form here — then docks back on close. No browser extension required.

Picture-in-Picture (always-on-top)

Request a PiP window on a click and append() the existing clipboard node into it. Since the SDK re-styles its shadow DOM for the new document, the moved node renders correctly. Listen for pagehide to dock it back.

Document Picture-in-Picture isn't available in this browser. Use Chrome or Edge 116+.

Picture-in-Picture can only be launched from a top-level page. Open this example in its own tab ↗

Source
// The clipboard stays bound to its form via `for` (resolved against
// the opener document), so it keeps autofilling after it floats.
const clip = document.getElementById('mc-widget');
const host = clip.parentElement;

popOutButton.onclick = async () => {
  const pip = await documentPictureInPicture
    .requestWindow({ width: 420, height: 560 });

  // SDK v0.3.0+ re-styles its shadow DOM for the new document, so the
  // real node can simply be moved in — no iframe, no re-instantiation.
  pip.document.body.append(clip);

  // Dock it back when the window closes
  pip.addEventListener('pagehide', () => host.append(clip));
};

Document Picture-in-Picture requires Chrome / Edge 116+. The window floats above other apps natively — no extension.
