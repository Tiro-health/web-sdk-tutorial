Magic Clipboard

Pop the live magic clipboard into an always-on-top Document Picture-in-Picture window so it floats above a separate PACS or viewer. The real component node is moved into the PiP window — same JS context, so it keeps working — and moved back when the window closes. No browser extension required.

Picture-in-Picture (always-on-top)

Request a PiP window on a click, clone the page styles into it, then append() the existing widget node. Listen for pagehide to dock it back.

Document Picture-in-Picture isn't available in this browser. Use Chrome or Edge 116+.

Picture-in-Picture can only be launched from a top-level page. Open this example in its own tab ↗

Source
// The widget = form-filler + magic-clipboard, bound by `for`.
const widget = document.getElementById('mc-widget');
const host   = widget.parentElement;

popOutButton.onclick = async () => {
  // 1. Open an always-on-top PiP window (needs a user gesture)
  const pip = await documentPictureInPicture
    .requestWindow({ width: 420, height: 560 });

  // 2. Clone the page's styles into the PiP document
  copyStyles(pip);

  // 3. Move the *real* node in — same JS context, keeps working
  pip.document.body.append(widget);

  // 4. Dock it back when the window closes
  pip.addEventListener('pagehide', () => host.append(widget));
};

Document Picture-in-Picture requires Chrome / Edge 116+. The window floats above other apps natively — no extension.
