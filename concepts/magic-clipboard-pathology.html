Magic Clipboard

Pathology reports often arrive as a single block of dictated free text. The magic clipboard reads that block and writes each finding into the right structured field — specimen, clinical history, gross description, microscopic description and diagnosis — on a multi-section <tiro-form-filler>. Same integration as the inline example: bind via for, then paste or dictate.

Surgical pathology report

A real dictation arrives as one unstructured stream — no section labels, no punctuation hints. Copy the transcript below, then click Autofill on the form. The clipboard splits the stream into the five fields. The questionnaire shape mirrors the Composition example, so the same response drives both downstream text generation and structured storage.

<!-- Load the Tiro Web SDK -->
<script src="https://cdn.tiro.health/.../tiro-web-sdk.iife.js"></script>

<!-- A multi-section pathology questionnaire -->
<tiro-form-filler id="path-report">
  <script type="application/fhir+json" slot="questionnaire">
  {
    "resourceType": "Questionnaire",
    "status": "active",
    "item": [{
      "linkId": "report", "type": "group",
      "text": "Surgical Pathology Report",
      "item": [
        { "linkId": "specimen",         "type": "text", "text": "Specimen" },
        { "linkId": "clinical-history", "type": "text", "text": "Clinical history" },
        { "linkId": "gross",            "type": "text", "text": "Gross description" },
        { "linkId": "microscopic",      "type": "text", "text": "Microscopic description" },
        { "linkId": "diagnosis",        "type": "text", "text": "Diagnosis" }
      ]
    }]
  }
  </script>
</tiro-form-filler>

<!-- Magic clipboard, bound to the form via `for` -->
<tiro-magic-clipboard for="path-report">
  <button type="submit">Autofill</button>
</tiro-magic-clipboard>
